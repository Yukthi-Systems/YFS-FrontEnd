# Shares

The **Shares** section of the sidebar gathers everything you share and
everything shared with you.

| View                | What it shows                                          |
| ------------------- | ------------------------------------------------------ |
| **Shared with you** | Folders other people have shared with you.             |
| **Shared by you**   | Folders you've shared with people in your organization.|
| **Shared by link**  | All the public links you've created.                   |

## Shared with You

What you can do depends on the permissions you were given:

| You want to…            | You need                       |
| ----------------------- | ------------------------------ |
| Open & preview          | Preview                        |
| Download                | Download                       |
| Upload or create        | Create                         |
| Rename or edit          | Edit                           |
| Move items              | Edit and Create                |
| Delete permanently      | Delete                         |

The shared folder itself can only be opened or downloaded — it isn't yours
to rename, move, or delete. The Details panel shows a summary of your
permissions for any shared item.

## Shared by You

Each folder offers **Open**, **Download**, and **Update the Share Settings**,
which reopens the sharing dialog to change who has access. **Open** takes
you to the folder in My Drive.

## Shared by Link

Lists every public link you've created, with its permissions, protection,
and expiry at a glance. Copy, share, edit, or revoke links from here — see
**Shared by Link** for the full guide.
