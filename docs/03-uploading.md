# Uploading Files & Folders

Uploads are resumable and run in the background, so you can keep working
while they finish.

## Ways to Upload

- **New → Upload File** or **New → Upload Folder** in the sidebar.
- **Right-click empty space** → Upload file or Upload folder.
- **Drag and drop** files or folders from your computer into the file area.

Folder uploads keep their internal structure. Remember that the top level of
My Drive only accepts folders.

## Upload Tray

Progress appears in the tray at the bottom-right. Click its header to
collapse or expand it.

| Status            | Meaning                                                    |
| ----------------- | ---------------------------------------------------------- |
| **Preparing…**    | The upload is being set up.                                |
| **Uploading**     | Sending data; a progress bar shows how far along it is.    |
| **Paused**        | Stopped by you — press Resume to continue.                 |
| **Reconnecting…** | The connection dropped; the upload resumes automatically.  |
| **Done**          | Finished successfully.                                     |
| **Error**         | The upload failed; the reason is shown underneath.         |

Use **Pause**, **Resume**, and **Cancel** on active uploads, and **Dismiss**
to clear finished ones. When everything is finished, the tray reads
"Uploads complete."

## Uploading into Shared Folders

In a folder someone shared with you, you need the **Create** permission to
add files. Without it, the New menu shows "You don't have permission to add
items here."

## Storage

Uploaded files count toward your storage quota, shown at the bottom of the
sidebar.
