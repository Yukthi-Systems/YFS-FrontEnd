# My Drive

My Drive holds everything you own. Open a folder by double-clicking it (or
tapping it on a phone), and use the breadcrumb trail above the list to jump
back up.

## Organizing Rules

The top level of My Drive holds **folders only**. Create or upload a folder
first, then put files inside it. At the top level, **Upload File** is hidden
and dropping loose files isn't accepted.

## Views

Switch views with the buttons at the top-right of the screen.

| View           | Best for                                                    |
| -------------- | ----------------------------------------------------------- |
| **List view**  | Details at a glance — name, owner, size, and modified date. |
| **Tiles view** | A compact card layout.                                      |
| **Grid view**  | Thumbnails. Choose **Small**, **Medium**, or **Large icons** from the menu beside the view buttons. |

List view isn't offered on phones. Your view, icon size, sort order, and
sidebar layout are saved to your account and follow you to other devices.

## Sorting & Refreshing

Use the sort menu above the list — **Sort by Name**, **Sort by Modified**,
or **Sort by Size** — and the **▲ / ▼** button to switch between ascending
and descending order. In List view you can also click a column heading. The
**Refresh** button reloads the folder from the server. Large folders load
more items as you scroll.

## Selecting Items

| Action                      | Result                                                     |
| --------------------------- | ---------------------------------------------------------- |
| **Click**                   | Selects the item and opens the Details panel. Click again to deselect. |
| **Ctrl/Cmd + click**        | Adds an item to, or removes it from, a multi-selection.    |
| **Shift + click**           | Selects every item between the last one you clicked and this one. |
| **Checkbox**                | Ticks items one at a time. The header checkbox in List view selects everything. |
| **Drag across empty space** | Draws a selection box around items.                        |

On phones, **long-press** an item to start selecting, then tap other items
to add or remove them.

## Selection Bar

When items are ticked, a bar shows how many are selected, with these actions:

| Action            | What it does                                     |
| ----------------- | ------------------------------------------------ |
| **Download**      | Downloads everything selected.                   |
| **Move to Trash** | Sends the selected items to Trash.               |
| **Delete**        | Deletes the selected items permanently, skipping Trash. |
| **Clear**         | Removes the selection.                           |

Buttons are disabled when nothing in the selection can be downloaded or
changed — for example, files that are still processing or locked. Hover over
a disabled button to see why.

## Item Actions

Right-click any item (or use its menu button) to see what you can do:

| Action                 | What it does                                               |
| ---------------------- | ---------------------------------------------------------- |
| **Open**               | Opens the folder (same as double-clicking).                |
| **Download**           | Downloads a file; folders download as .zip or .tar.        |
| **Rename**             | Changes the item's name.                                   |
| **Version History**    | Shows earlier versions of a file.                          |
| **Move to…**           | Moves the item to another folder.                          |
| **Share**              | Opens the sharing dialog.                                  |
| **Colour & icon**      | Gives a folder a custom colour and icon.                   |
| **Move to Trash**      | Sends the item to Trash.                                   |
| **Delete Permanently** | Deletes the item right away, skipping Trash.               |

You can also move items by dragging them onto a folder. Right-clicking empty
space offers **Create folder**, **Upload file**, **Upload folder**, and
**Refresh**.

## Item States

| State          | Meaning                                                           |
| -------------- | ----------------------------------------------------------------- |
| **Processing** | Still being processed on the server; can't be opened or downloaded yet. |
| **Failed**     | Processing never finished; the file can't be previewed or downloaded.   |
| **Locked**     | The file is in use; renaming, moving, and deleting are paused.          |

## Details Panel

Click an item once to open the Details panel on the right.

| Field                  | Shows                                                    |
| ---------------------- | -------------------------------------------------------- |
| **Preview**            | A thumbnail, or a player for audio and video. Click it to open the full viewer. |
| **Description**        | A note about the item, visible to everyone who has access to it. |
| **Kind**               | The file type and extension.                             |
| **Contains**           | For folders: how many folders and files are directly inside. Shows "Counting…" briefly while the contents load. |
| **Version**            | The file's current version number.                       |
| **Owner**              | Who owns the item.                                       |
| **Created by**         | Who created it.                                          |
| **Location**           | The folder path, such as My Drive › Projects › Q3.       |
| **Size**               | The item's size, including everything inside a folder.   |
| **Modified / Created** | When it was last changed and when it was created.        |
| **Status**             | In Trash, Locked, Processing, or Failed, when applicable. |
| **Permissions**        | For shared items: Full Access, View & Download, View only, or a list of what's allowed. Hover for the full breakdown. |
| **ID**                 | The item's unique ID, with a **Copy** button.            |

To add a description, click **Add a description** (or click an existing one
to change it). Descriptions can be up to 2,000 characters. Press **Save** or
**Ctrl/Cmd + Enter** to save, and **Esc** to cancel. Changing a description
on a shared item requires the **Edit** permission.

The buttons at the bottom of the panel offer **Open**, **Download**,
**Rename**, **Version History**, **Move**, **Share**, and **Move to Trash**
(or **Restore Item** for items in Trash), depending on the item and your
permissions.
