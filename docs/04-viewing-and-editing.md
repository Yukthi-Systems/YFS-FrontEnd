# Viewing & Editing Files

Double-click a file (or select it and press Enter) to open it. On a phone,
tap it. You can also click the preview in the Details panel.

## What Opens Where

| File type                                                   | Opens in                                       |
| ----------------------------------------------------------- | ---------------------------------------------- |
| **Images** (PNG, JPG, GIF, SVG, WebP, and more)             | Image viewer.                                  |
| **Video & audio**                                           | Streaming player — no full download needed.    |
| **Documents, spreadsheets, presentations, drawings, PDFs, plain text (.txt), and Markdown (.md)** | Collabora Online, where you can view and edit them. |
| **Code & config files** (.js, .py, .json, .yml, .log, .ini, and more) | Read-only viewer with syntax highlighting and line numbers. |

Other file types show "No preview available for this file type" — download
them instead.

## Viewer Controls

- **← / →** or the side arrows move to the previous or next file in the folder.
- **Full view** enlarges images and code to fill the screen.
- **Minimize** shrinks a video into a floating player so you can keep browsing.
- **Download** saves the current file.
- **Esc** or the close button exits the viewer.

On phones the viewer goes full-screen; swipe left or right to move between
files.

## Editing in Collabora Online

Documents, spreadsheets, presentations, and other office files open in
Collabora Online, with its own ribbon and toolbar.

- Your changes are saved when you close the editor or move to another file.
- The ← / → keys don't switch files while the editor is open, so you don't
  leave a document by accident.
- If the editor stays blank, use the **Open in a new tab** button at the
  bottom-right.

In folders shared with you, editing requires the **Edit** permission;
without it, files open read-only. Earlier versions opened from Version
History are always read-only.

## Code & Text Files

Code and config files open in a read-only viewer. To change one, download
it, edit it on your computer, and upload it again. Files larger than 2 MB
can't be previewed as text — download them to open.

## When a File Won't Open

| Message                                   | Meaning                                                  |
| ----------------------------------------- | -------------------------------------------------------- |
| **File is currently processing**          | Try again once server processing finishes.               |
| **File failed to process**                | The file never finished processing on the server.        |
| **This file can't be previewed**          | The content doesn't match its extension — it may be corrupted or misnamed. Download it to inspect. |
| **This file is too large to preview as text** | Over 2 MB; download it instead.                     |
| **This file contains characters that can't be displayed as text** | It isn't really a text file; download it instead. |
