# Opening a Shared Link

This page is for anyone who receives a YFS share link. No account is
needed.

## Getting Access

The owner may protect a link in one of these ways:

| Protection          | What to do                                                    |
| ------------------- | ------------------------------------------------------------- |
| **Password**        | Enter the password and press Unlock.                          |
| **Verification**    | Enter an approved email or phone number, then the 6-digit code sent to it. |

If you don't receive a code, you can request a new one after a 3-minute
wait, or switch to a different address. A link can use both a password and
verification.

## Browsing a Shared Folder

Once inside, you can open subfolders, switch between views, sort, and
refresh. Folders are listed first. A note from the owner, if any, appears at
the top. Depending on the link's permissions you may also:

- **Create folders** with the New folder button.
- **Rename folders** from the right-click menu.
- **Move folders** — choose Move to…, open the destination, then press
  **Move here**.

Opening and downloading individual files from a shared link isn't available
yet. If you need a file, ask the owner to share it with your YFS account.

## Leaving

Press **Exit** at the top-right to end your session.

## Problems Opening a Link

| Message                     | Meaning                                              |
| --------------------------- | ---------------------------------------------------- |
| **This link has expired**   | The owner set an end date. Ask them for a new link.  |
| **Link not found**          | The link doesn't exist or was removed.               |
| **Couldn't open this link** | A connection problem — press Try again.              |
