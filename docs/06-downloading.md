# Downloading

## Files

Download a file from its right-click menu, the Details panel, or the viewer.
Images, video, audio, and PDFs open in a new browser tab, where you can view
or save them; other files download directly.

Files that are still processing or failed to process can't be downloaded.

## Folders

Folders are packaged into an archive on the server.

- **Download as .zip** — the default.
- Use the arrow next to it to pick **.zip** or **.tar** instead.

Progress appears in the download tray at the bottom-right, showing how many
files and bytes have been packed. When the archive is ready it downloads
automatically. If it fails or expires before downloading, the tray tells you
why.

## Multiple Items

Tick several items and press **Download** in the selection bar.

## Shared Items

In folders shared with you, downloading requires the **Download**
permission.
