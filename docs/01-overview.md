# Yukthi File System Documentation

Welcome to the documentation for Yukthi File System (YFS). This guide covers
everything you need to store, preview, edit, and share files and folders
from your browser.

## Left Navigation

| Menu        | What it's for                                                         |
| ----------- | --------------------------------------------------------------------- |
| **New**     | Create a folder, upload files, or upload a whole folder.              |
| **My Drive**| Your own files and folders.                                           |
| **Shares**  | Expands to Shared with you, Shared by you, and Shared by link.        |
| **Trash**   | Deleted items, ready to restore or remove for good.                   |
| **Storage** | How much of your quota is used, and how many files you have.          |
| **Account** | Your avatar and name — opens Profile, Theme, Accent color, and Sign out. |

Your organization's name appears at the top of the sidebar. The **Shares**
section only appears when sharing is enabled for your organization. Use the
arrow next to the organization name to collapse the sidebar to icons; on
phones, the menu button in the top bar opens it.

## Top Bar

| Feature            | What it does                                                    |
| ------------------ | --------------------------------------------------------------- |
| **Search**         | Find files and folders by name and by the text inside them.     |
| **View mode**      | Switch between List view, Tiles view, and Grid view.            |
| **Icon size**      | In Grid view, choose Small, Medium, or Large icons.             |

## Above the File List

- **Breadcrumbs** show where you are; click any part to jump back up.
- **Sort controls** change the order of items and include a **Refresh** button.
- **Selection bar** appears when you tick items, with actions for all of them at once.

## Trays & Notifications

Uploads and folder downloads run in the background. Their progress appears
in trays at the bottom-right of the screen, and short confirmation or error
messages appear as pop-up notifications.

## Key Capabilities

- **Resumable uploads** — large files and whole folders upload in chunks,
  survive network drops, and can be paused or cancelled.
- **In-browser previews & editing** — images, video, audio, and code open in
  built-in viewers; documents, spreadsheets, presentations, and PDFs open in
  Collabora Online, where you can also edit them.
- **Version history** — view, download, and delete earlier versions of a file.
- **Sharing** — share folders with people in your organization, or create
  public links protected by passwords, one-time codes, and expiry dates.
- **Trash** — restore deleted items or remove them permanently.
