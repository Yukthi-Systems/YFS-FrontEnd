# Search

Type in the search box at the top of the screen. Results replace the file
list until you clear the box.

## Where Search Looks

| You're in           | Search covers                                              |
| ------------------- | ---------------------------------------------------------- |
| **My Drive**        | The folder you're in and every folder below it.            |
| **Shared with you** | Folders shared with you and their contents.                |
| **Trash**           | Items in Trash, or inside the trashed folder you've opened. |

Search isn't available on the **Shared by you** and **Shared by link** pages.

## Name and Content Matches

- **Name matches** appear instantly as you type.
- **Content matches** — files whose text contains your search — are added
  once you've typed at least 2 characters. Each shows a snippet with the
  matching text. A loading indicator shows while content search runs.

## Only Opened Folders Are Searched

Search runs in your browser over the folders the app has already loaded —
the ones you've opened. If a file you expect doesn't show up, open the
folder that contains it, then search again.

## Using Results

- Double-click a folder to open it (this clears the search), or a file to
  open it in the viewer.
- Right-click a result for the usual actions (download, rename, share, and
  so on).
- Folders that are in Trash can't be opened from search results.
